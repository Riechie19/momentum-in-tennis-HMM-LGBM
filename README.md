# Taking the Swing: Momentum in Tennis
This project explores the concept of psychological momentum in tennis, analyzing its impact on match progression and outcomes using mathematical models. A real-time win probability model, based on a Hierarchical Markov Chain, tracks match dynamics. Additionally, LightGBM and SHAP analyses reveal that winning previous games and securing the first serve provide a significant competitive edge. Despite these findings, the study supports the claim that momentum has limited influence on tennis match outcomes. This research was submitted as a solution for Problem C in the Mathematical Contest in Modeling (MCM) 2024.
